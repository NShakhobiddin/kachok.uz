# Qayta yaratilishi kerak bo'lgan mashq rasmlari

2026-10-29 dagi tekshiruv natijasi. Har bir rasm va uning ikkinchi kadri (harakat), mushak yorliqlari va texnika belgilari kattalashtirib ko'rildi.

Yorliq va belgilar joyi, rasmga zid matnlar ilovada allaqachon tuzatilgan. Quyidagilar esa faqat rasmni qayta yaratish bilan tuzaladi.

Hozircha ilovada:
- Texnikasi xato ikkinchi kadrlar olib tashlangan: mashq sahifasida "Harakat" tabi chiqmaydi, faqat mushaklar va texnika rasmi qoladi.
- Ikkinchi kadri to'g'riroq bo'lgan mashqlarda o'sha kadr asosiy rasm qilib olingan: step-up, hammer-curl, cable-fly, db-bench.

Generatsiya tartibi: `scripts/images/README.md`. Ikkinchi kadr asosiy rasmdan tahrirlab yaratiladi: o'sha kamera, o'sha odam, o'sha jihoz.

## Asosiy rasm xato (ikkala kadr ham kerak)

| Mashq | Muammo | Kerakli holat |
|---|---|---|
| hack-squat | Bel yostiqdan ajralgan | Bel qiya yostiqqa to'liq tegib turadi, oyoqlar platformada. Yuqori nuqtada yelka yostig'i va bel yostig'i birga ko'tariladi |
| leg-extension | Tizza mashina o'qidan ancha oldinda, qo'llar sonda | Tizza o'q bilan bir chiziqda, bel suyanchiqda, qo'llar dastakda |
| leg-curl | Ikkinchi kadr aslida oyoq yozish holati | Rolik tovon ustida (Axill payi sohasida), bel suyanchiqda |
| calf-raise | "Yuqori nuqta" emas: tovon ko'tarilmagan | Tovonlar baland ko'tarilgan (yuqori) va zinadan pastga tushgan (pastki) holatlar |
| bulgarian | Orqa oyoq skameykadan ~3% yuqorida osilgan | Orqa oyoq kafti skameyka yostig'ida |
| hip-thrust | Pastki nuqtada tos deyarli tushmagan, shorti buzilgan | Tos polga tomon ~90° bukilgan, shtanga tos bilan birga harakatlanadi; iyak biroz ichkariga |
| step-up | Tepada qutida tik turgan holat yo'q | Qutida to'liq tik turish (yuqori nuqta) |
| front-squat | Profilda disk boshni yopadi, shtanga old deltada emas | 3/4 old-yon burchak: shtanga old delta/o'mrovda, tirsaklar baland, yuz ko'rinadi |
| inverted-row | Asosiy kadrda qo'l bosh ustidan o'ralgan; ikkinchida ko'krak yonadi | Turnik yonidan (3/4) ko'rinish, qo'llar yelka kengligida; yuqorida ko'krak turnikka tegadi, pastda qo'llar to'g'ri |
| chin-up | Ushlash kaft pastga (bu tortilish) va yelkadan keng | Kaftlar o'ziga qaragan, yelka kengligida |
| db-shrug | Ikki kadr bir xil | Yelkalar quloq tomon ko'tarilgan (yuqori) va bo'shashgan (pastki) holat |
| overhead-extension | Ikkinchi kadrda gantel ikkita bo'lib chizilgan | Bitta gantel, ikki qo'l yuqori boshini ushlaydi, qo'llar tepada to'g'ri |
| cable-crunch | Ikki kadr bir xil, bukilish yo'q; blokka orqa o'girgan | Blok tomonga qarab tiz cho'kkan; qovurg'a tosga bukilgan holat |
| dead-bug | Cho'zilgan qo'l va oyoq bir tomonda | Qarama-qarshi qo'l va oyoq cho'zilgan, poldan biroz yuqorida; boshlang'ich holat ham kerak |
| push-up | Pastda bilaklar polga yotgan; ikkinchi kadrda qo'l gantelda | Kaftlar polda ko'krak pasti ostida, bilak tik, tirsak ~45° |
| cable-fly | Asosiy kadrda qo'llar bukilib qorin oldida | Qisqargan holat: qo'llar oldinda, tirsak burchagi o'zgarmagan, dastaklar ko'krak pasti oldida |
| ohp | Asosiy kadr to'liq yozilmagan, ikkinchida shtanga iyak ustida | Boshlanish: shtanga old delta/o'mrovda. Yuqori: qo'llar to'liq yozilgan, shtanga oyoq kafti o'rtasi ustida |
| db-bench | Pastki nuqtada bilak qiya, gantel bo'yin ustida | Pastki nuqta: bilaklar tik, gantellar ko'krak o'rtasi yonida |
| machine-chest-press | Dastaklar havoda osilgan, richag yo'q | Haqiqiy o'tirib ko'krak trenajyori; boshlanish: dastaklar ko'krak yonida |
| machine-shoulder-press | Dastaklar havoda osilgan | Haqiqiy yelka trenajyori; boshlanish: dastaklar bosh yonida yelka sathida |
| pike-push-up | Bilaklar polga yotgan (dolphin) | Bilaklar tik, bosh qo'llar oldida polga yaqin |
| reverse-fly | Lenta bel ustidagi qattiq lime tayoq bo'lib chizilgan | Neytral rangli elastik lenta ko'krak oldida |
| lateral-raise | Gantel dastasi bilak bo'ylab | Dasta kaft bo'ylab (ko'ndalang), ikki kadrda bir xil |
| hammer-curl | Yuqori kadrda kaft yuqoriga qaragan | Bolg'a ushlashi (kaftlar bir-biriga) — yuqori va pastki holat |
| cable-row | Ikkinchi kadrda trosning bloki boshqa joyda | Ikkala kadrda pastki blok, boshlanishda qo'llar oldinga cho'zilgan |
