# GYMbos brendi

Manba: `GYMbos_logo.html` (dizayn fayli). Ilovada:

- **Logo** — `src/components/Logo.tsx` (`<Logo size={30} />`): lime tugma ichida **GYM** (ikki tomonida shtanga disklari) + **bos**.
  Variantlar: `tone="light"` (oq fon), `tone="lime"` (lime fon — tugma qora), `bos={false}` (faqat tugma), `intro` (tugma bosiladi, keyin "bos" chiqadi), `flat` (soyasiz).
- **Shrift** — Big Shoulders 700/900 (`public/fonts/big-shoulders.woff2`, SIL OFL 1.1), ilova matni — Manrope.
- **Ranglar** — lime `#D4FA50`, lime soya `#9DB93B`, qora `#0B0B0C`, oq `#F2F2EE`, kulrang `#8A8F87`.
- **Shior** — «Gapirma — bos.»
- **Ikonkalar** — `public/icon.svg` (favicon, sodda belgi), `icon-192/512.png`, `icon-maskable-512.png` (Android), `apple-touch-icon.png` (iOS);
  `docs/brand/telegram-avatar.png` — Telegram kanal/bot avatari (doira ichida).
- **Intro** — `index.html` dagi yuklanish ekrani: ilova yuklanguncha logo animatsiyasi (React o'rnini egallagach yo'qoladi, kutish qo'shmaydi).

Ichki nomlar (localStorage `kachok-v1`, kesh nomlari, repozitoriy) o'zgartirilmadi — foydalanuvchi ma'lumotlari saqlanib qoladi.
